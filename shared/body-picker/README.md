# shared/body-picker

Общий код подбора типового упражнения по схеме тела (BACKLOG 762 срез 2, вариант Б).
Используют `web-workouts` и `web-dashboard`. Правило: здесь только то, что нужно обоим; чистые TS-модули без импортов из пилотов
(строки приходят параметрами, не из i18n пилота). Подключение — относительным импортом `../../../shared/body-picker/<модуль>`.
Тесты модулей лежат у `web-workouts` (там они жили до выноса) и служат стражем.
