# shared/exercise-catalog — каталог основных упражнений зала

BACKLOG 69.21, запрос владельца 2026-11-02: «список основных упражнений из спортзала, визуализация, чётко по группам мышц, поэтапно».

**Этап 1 (сделан, без интерфейса):** данные `catalog.ts` — 70 упражнений, 12 групп мышц (те же `MuscleId`, что у карты мышц), оборудование (штанга, гантели, тренажёр, блок, свой вес),
тип (базовое / изолирующее), вторичные мышцы и одна короткая подсказка по технике на RU и EN.

Главные ограничения (держит страж `web-workouts/src/exerciseCatalog.test.ts`):
- каноническое название (RU и EN) должно сопоставляться картой мышц (`musclesForExercise`) с ТОЙ ЖЕ главной группой — иначе упражнение из каталога попадёт на карту не туда;
- id уникальны и в `snake_case`, названия уникальны, у каждой из 12 групп не меньше двух упражнений, вторичные мышцы настоящие и без главной;
- подсказки RU без «вы»-форм (в проекте «ты» или безлично).

Как использовать: `import { CATALOG, GROUP_ORDER, catalogByGroup, catalogForMuscle } from '../../shared/exercise-catalog/catalog'`. Модуль чистый (только тип `MuscleId`),
подписи интерфейса (названия групп, «Штанга» и т. п. кроме `EQUIPMENT_NAMES`) приходят из пилота.

Добавляя упражнение: проверьте, что его русское и английское название ловится правилами `shared/body-picker/muscles.ts` (при необходимости допишите слово-ключ в существующее правило,
порядок правил важен — первое совпавшее выигрывает), и запустите страж.

**Дальше (бэклог 69.21):** этап 2 — экран «Каталог» в «Тренировках» (разделы по группам, мини-силуэт с подсветкой мышц, «добавить в мои упражнения»); этап 3 — схематичные SVG-иллюстрации
движения (два положения); этап 4 — поиск, «что тренировать сегодня», связка с вариантами упражнений.
