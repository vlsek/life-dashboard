# A — предварительная проверка hit areas задних предплечий

Дата: 2026-11-09. Исследовательский материал, не production-изменение.

## Что выявлено в v2

Вариант v2 использовал соседние вертикальные интервалы: разгибатели `y=73..87`, сгибатели `y=87..101`. В Chromium на границе из-за субпиксельного преобразования и округления координат точки, расположенные у нижнего края области разгибателей, попадали в следующую область сгибателей. Поэтому простое отсутствие пересечения координатных прямоугольников не гарантировало корректный hit-test на экране.

## Кандидат v3

Файл: `docs/mockups/muscle-map-a-hitarea-candidate-v3.html`.

- разгибатели: `y=73..87`;
- сгибатели: `y=89..103`;
- между областями оставлен зазор 2 единицы `viewBox`;
- мужская модель: левая `x=14..32`, правая `x=68..86`;
- женская модель: левая `x=18..34`, правая `x=66..82`;
- видимые анатомические контуры не изменялись.

## Выполненная Chromium-проверка

Проверен **изолированный SVG-fixture**, собранный из точных hit-path и соседних видимых path исходного кандидата; порядок релевантных групп сохранён. Это не полный HTML-прогон прототипа и не проверка production-компонента.

Для каждой из 8 областей проверена сетка 7×7 (49 точек на область) через `document.elementFromPoint`; также по одному клику в центре каждой области с проверкой всплытия события до ожидаемой группы.

| Ширина окна | Точек hit-test | Ошибки | Всплытие 8 кликов | Минимальный размер цели |
|---:|---:|---:|---|---:|
| 360 px | 392 | 0 | 8/8 | 51.8 × 45.4 CSS px |
| 390 px | 392 | 0 | 8/8 | 56.6 × 49.6 CSS px |
| 1280 px | 392 | 0 | 8/8 | 42.4 × 37.1 CSS px |

Fixture воспроизводил responsive grid и размеры карточек/SVG из прототипа: одна колонка до 480 px, две до 900 px, четыре на desktop; на 1280 px максимальная высота SVG 470 px уменьшает цель примерно до 42.4×37.1 px. На мобильных 360/390 px цели превышают 44×44 px; desktop-проверка использует нижний порог 24 px. Результат относится только к изолированному fixture. В нём не проверялись полный DOM всех четырёх SVG, фактический JavaScript приложения, фокус/клавиатура, консоль полного документа, скринридеры и реальный телефон. Поэтому не объявлять v3 окончательно проверенным.

## Следующий браузерный шаг

В репозитории добавлен `scripts/check_muscle_map_hitareas.py`: он запускает полный HTML-кандидат в Chromium на 360/390/1280 px, проверяет ссылки и уникальность hit areas, 7×7 точек каждого hit path, всплытие клика, размеры целей, клавиатурный Enter/Space, горизонтальное переполнение и ошибки консоли. Скрипт подготовлен для следующего запуска в полном checkout проекта; здесь он ещё не выполнялся на полном документе.
