# 73.1 — Сводка прогресса за период (предложение агента 7, 2026-10-28)

Статус: **предложение, кода нет.** Макет: `docs/mockups/progress_summary.html` (три варианта + состояния).

## Что есть сейчас
- «История» живёт в `web-calendar` (`HistoryView.vue`; `web-history` только перенаправляет на `/calendar/?view=history`).
- Уже считается: прогресс дня и недели (`historyStats.ts`: `dayStats`, `weekStats`), статистика месяца (среднее, дни на 100%, отслеженные дни), кольцо по категориям (`MonthCategoryChart.vue`, `categoryDonut.ts`), переключатели «Показывать …» (`calendarShow.ts`).
- Грузится: метрики, `daily_values`, `daily_notes`, цели (`useHistoryData.ts`). **Новых таблиц и миграций для сводки не нужно** — всё считается на клиенте из этих данных.
- Нет: выбора периода «неделя / месяц / год», сравнения с прошлым периодом, списков «стало лучше / хуже», числа тренировок и целей за период.

## Предлагаемый срез 1 (после выбора варианта)
1. Чистый модуль `periodSummary.ts` (без Vue): на входе период и данные, на выходе итоги, сравнение с прошлым периодом и список метрик «лучше / хуже / мало данных». Тесты на границы (первый день, пропущенные дни, пустой период, смена месяца/года, часовой пояс).
2. Карточка «Сводка» в «Истории» над сеткой месяца, переключатель Неделя/Месяц/Год, стрелки периода, включение через «Показывать …».
3. Состояния: мало данных, нет прошлого периода, загрузка, ошибка с «Повторить», офлайн.
4. Без SQL, версия X.NN после `git fetch`, проверка Chromium на 390 px и ПК.

## Правила честности (по пункту 73.5)
- Сравниваем только если в обоих периодах отслежено **не меньше 60% дней** (порог — вопрос 4).
- Пропущенные пользователем дни (`skipped_days`) не считаются ни за выполненные, ни за невыполненные.
- Прошлые дни не пересчитываем (решение владельца 2026-10-03, `planned_sets_log`).
- Улучшение/ухудшение — со знаком и стрелкой, не только цветом. «Лучше» для метрик «не больше N» — это меньше.
- Никаких «инсайтов» на коротких рядах: если данных мало, строка пишется как «мало данных».

## Вопросы владельцу (с моими предложениями)
1. **Какой вариант вида?** А «плитки» / Б «рассказ» / В «таблица». *Предлагаю А как основу, Б — одной строкой над плитками, В — по нажатию «Все метрики».*
2. **Куда класть?** Над сеткой месяца в «Истории» / отдельная вкладка «Сводка» / в окно «прогресс дня». *Предлагаю вкладку-переключатель вида в «Истории» (как уже решено в 73.4), по умолчанию — «Месяц».*
3. **Какие периоды?** Неделя, месяц, год / ещё «свой». *Предлагаю неделя/месяц/год, «свой» — отдельным срезом.*
4. **Порог данных для сравнения.** *Предлагаю 60% отслеженных дней в обоих периодах, иначе «мало данных».*
5. **Что считать «лучше»?** Для метрик с целью — доля дней с выполненной целью; без цели — среднее значение. *Предлагаю так; без цели стрелку показываем нейтральной (▲/▼ серым), чтобы не судить за вас.*
6. **Тренировки и цели в сводке.** Считать тренировки по метрикам-упражнениям и дням с записью, цели — по выполненным этапам за период. *Предлагаю так, пока нет «сессий» из 69.1; потом перейти на них.*
7. **Прошлый год.** Если ведёшь меньше года — показывать «данные за N мес.» и не сравнивать. *Предлагаю так.*
8. **Баллы и монетки в сводке?** Не уверен, нужны ли. *Предлагаю не включать в срез 1, отдельным вопросом позже.*
9. **Можно ли делиться сводкой (картинка/друзьям)?** *Предлагаю не делать в срезе 1.*
