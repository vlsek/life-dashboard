# Аудит фронтенда страниц (BACKLOG 60.2 п.4) — агент 1, 2026-10-12

Как повторить: `python3 -m http.server 8765` в корне репозитория, затем `node scripts/audit_pages.mjs [страница ...]` (нужны playwright и chromium).
Скрипт открывает все 14 страниц пилотов на мок-данных Supabase в четырёх режимах — телефон 390 × десктоп 1280, светлая и тёмная тема — и ищет:
горизонтальную прокрутку страницы, элементы шире экрана (вне горизонтальных контейнеров), ошибки консоли и страницы, пустые страницы, редиректы,
цели нажатия мельче 28 px на телефоне. Полный JSON — в `/tmp/audit.json`.

## Результат прогона 56 режимов (14 страниц × 4)

**Чисто:** горизонтальной прокрутки нет нигде; элементов шире экрана нет; ошибок JS в консоли нет; пустых страниц нет; десктоп без замечаний.
`history` честно редиректит на `calendar` (так задумано).
