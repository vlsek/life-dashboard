# «Кастомизация»: капитальная переделка структуры (BACKLOG 64.1)

Запрос владельца (2026-10-17, давний): «Навести порядок в разделе кастомизации — можно хоть капитально перелопатить. Сейчас там бардак, чёрт ногу сломит.
Посмотреть, как подобные разделы реализуются на рынке, и сделать по аналогии».

## Что сейчас (диагноз по коду `web-customization`)

Страница накладывает друг на друга **четыре независимых способа навигации**, и человек должен держать их все в голове:
1. Вкладки-группы по «задаче» (оформление, главная, вода, графики, загрузка, прочее + «Все») — `pageTabs.ts`.
2. Внутри группы — **разделы** (`SectionGroup`), в каждом свой счётчик «открыто/всего» и сворачивание.
3. Внутри раздела — **подгруппы по редкости** (`RarityGroup`), тоже сворачиваемые.
4. Поверх всего — **фильтры «Показывать:»** (куплено / за достижения / за монеты / любимое …, `VisibilityChips`) и блок «Сейчас выбрано».

Дальше — шесть разных «пикеров» с разной механикой (`ThemeCard`, `ItemCard`, `SplashPicker`, `StreakFlamePicker`, `WaterAnimPicker`, `BodyModelPicker`, `ChartMarkerPicker`, `ChartLinePicker`),
из них часть без цены/редкости. Каталог тоже неровный: рамки аватара — 26 предметов, остальные категории по 6–7, ещё пять разделов — «бесплатные» с жёсткими числами в шаблоне (`:total="4"`).
Итого: «что на мне сейчас», «что я могу купить» и «что у меня есть» — **в одной ленте**, а название раздела — внутренний ключ каталога (`collapse_style`, `week_gauge`…), а не то, что человек узнаёт в интерфейсе.

## Как это делают на рынке

- **Fortnite, «Locker».** Экран строится от **слотов** («Облик», «Рюкзак», «Кирка», «Эмоции»…): слева слоты, в центре предпросмотр персонажа, справа предметы выбранного слота. Предмет можно «Предпросмотр» → «Надеть»; есть поиск и сортировка по редкости; **пресеты («Loadouts»)** — сохранить сочетание под именем и надевать одним нажатием (до 100). Урок по критике: когда пресет стал собираться за 11 кликов вместо 2, игроки возмутились — лишние клики убивают такой экран.
- **Discord, «Профили» + «Магазин».** Предметы сгруппированы по тому, **какую часть профиля они меняют**: рамка аватара, эффект профиля, плашка имени, рамка профиля. Купленное лежит в «коллекции» (в «Профилях» — кнопка «Изменить …»: надеть или перейти в магазин за новым); покупка — в **отдельном «Магазине»** с поиском, фильтрами и наборами. Каждая вещь с живым предпросмотром, «Применить» только у уже купленных.
- Общее у обоих: **слот = место, где вещь видна**, а не тип каталога; **«надето» и «магазин» разведены**; **предпросмотр до применения**; редкость — значок и сортировка, а не отдельный уровень вложенности.

## Предложение (на согласование владельцу, срезами)

**Принцип:** один главный способ навигации — слоты; всё остальное — вспомогательное.

1. **Слоты — по смыслу для человека** (имена из интерфейса, а не ключи каталога): «Тема», «Аватар (рамка)», «Тело (модель)», «Свёртывание блоков», «Шкала дня», «Прогресс недели», «Огонь серии», «Вода (анимация, стакан)», «Графики (метки, линия)», «Загрузка».
   Слот = одна карточка-«ячейка» с превью текущего выбора.
2. **Экран-«витрина» из ячеек** (как слоты Locker): сетка ячеек слотов, на каждой — превью надетого, подпись, «n/m открыто». Нажатие открывает слот: **сетка предметов этого слота**, одна и та же карточка для всех слотов (превью, название, редкость значком, цена/условие, «Надеть» / «Купить» / «Примерить»).
3. **Внутри слота три переключателя вместо четырёх уровней:** «Все · Мои · Магазин» (+ «Любимые»), поиск, сортировка (редкость / цена / новые). Подгрупп по редкости больше нет — редкость значком и сортировкой.
4. **Один блок «Сейчас на мне» сверху** (как сводка Locker): все слоты одним взглядом, нажатие ведёт в слот.
5. **Образы (пресеты)** — сохранить текущее сочетание темы, рамки, шкал и т. д. под именем и надеть одним нажатием (3–5 штук; как Loadouts). Отдельным срезом, после слотов.
6. **Каталог выровнять:** убрать числа из шаблона (`:total="4"`), «бесплатные» пикеры привести к общей карточке; новое — «Новое» значком. Новые предметы добавляются в слот одной записью каталога.

## Срезы

0. ✅ Документ и запись в BACKLOG (этот файл).
1. Карта слотов: файл `slots.ts` (id, название, превью, предметы, группа) + тесты на полноту (каждый предмет каталога в слоте); без изменения экрана.
2. Экран-витрина: ячейки слотов + «Сейчас на мне» (заменяет вкладки-группы и ленту), старые разделы временно открываются из ячейки.
3. Экран слота: единая карточка, переключатель «Все · Мои · Магазин», поиск, сортировка; редкость значком.
4. Пикеры без цены (загрузка, пламя, метки, линия, модель тела) в общую карточку.
5. Образы (пресеты).

## Правила для агентов

- **Другие агенты добавляют новые предметы** («если задач нет — новые предметы в разделы, где их меньше всего»). Это совместимо: предмет — запись каталога, слот его подхватит. **Не менять `App.vue` страницы «Кастомизация»** и `pageTabs.ts` без согласования с автором этой переделки, пока идёт срез 2.
- Каталог (`customization.ts`) и пикеры можно дополнять; страж «у каждой категории есть слот» будет добавлен в срезе 1.

## Срез 5: «Образы» — устройство (агент 7, 2026-10-19)

**Что такое образ.** Сохранённое сочетание: тема + выбор из каталога (`profiles.customization`) + выбор «бесплатных» пикеров (ключи `localStorage`: заставка, огонёк серии, анимация воды, метка/линия/анимация/прогноз/вид/зона цели/спарклайны графиков, модель тела). До 5 образов, имя до 24 знаков.

**Находка.** Выбор «бесплатных» пикеров живёт только в `localStorage` и **между устройствами не синхронизируется** (в `SYNC_KEYS` их нет). Образ снимает их вместе с остальным и едет в профиль сам, поэтому «надеть образ» на другом устройстве заодно переносит и их.

**Хранение.** По ключу на образ: `cust_look_l1 … cust_look_l5` (JSON `{n, t, s, p}` ≤ 1900 знаков при лимите синхронизации 2000). Префикс `cust_look_` добавлен в `SYNC_PREFIXES` шапки (ui_settings, миграция 064), SQL не нужен. Код: `web-customization/src/lib/looks.ts` (снимок, разбор, сохранение, переименование, план применения).

**Применение.** `planApply` ничего не пишет: считает итоговый выбор, пропуская недоступное (закрытая тема, предмет, которого нет у человека) и считая пропущенное для сообщения. Чего нет в образе — снимается/сбрасывается «по умолчанию», чтобы образ полностью задавал вид. Запись: один `profiles.update({customization})`, тема через менеджер тем, ключи пикеров в `localStorage`, затем перезагрузка страницы (как при переключении записей, владелец согласен с перезагрузкой).

**Порядок.** 5a ✅ логика + синхронизация + тесты; 5b экран «Образы» (ячейка витрины, список, «Сохранить текущий вид», «Надеть», «Переименовать», «Удалить», сообщение о пропущенном).
