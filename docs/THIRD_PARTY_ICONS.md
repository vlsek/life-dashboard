# Сторонние иконки

Наборы «Заливка» и «Дуотон» в разделе «Стиль иконок» («Кастомизация») построены на иконках **Phosphor Icons** (варианты `fill` и `duotone`).
Файлы наборов — `web-header/public/icon-packs/fill.json` и `duotone.json` (генерирует `scripts/gen_icon_packs.py` из пакета `@phosphor-icons/core` 2.1.1;
пакет в репозитории не хранится). Набор «Пиксели» — растеризация собственных иконок проекта, сторонних материалов не содержит.
